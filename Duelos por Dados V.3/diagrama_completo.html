📋 Strategy

Clases: EstrategiaCarta + 4 implementaciones

Permite cambiar comportamiento de cartas en tiempo de ejecución.

🏭 Factory Method

Crea instancias de 9 tipos diferentes de objetos.

♻️ Object Pool

Clase: ObjectPoolObjetos

Reutiliza objetos para mejorar rendimiento del juego.

🎭 Facade

Clase: InventarioFacade

Simplifica interfaz compleja del Object Pool para el jugador.

Clases: MementoTirada, GestorMemento

⛓️ Chain of Responsibility

Clases: HandlerTurno + 3 handlers

Procesa fases del turno: Inicio → Acción → Fin.

🔄 Flujos Principales

Flujo 1: Usar una Carta

Jugador selecciona Carta ↓ Carta.puede_usarse() → Verifica si ya fue usada ↓ Estrategia.aplicar(actor, objetivo, potencia) ├→ EstrategiaAtaque: daño = potencia + bono_ataque ├→ EstrategiaCura: cura = potencia ├→ EstrategiaDefensa: escudo = 1 + potencia └→ EstrategiaObjetos: obtiene objeto del pool

Flujo 2: Obtener Objeto

Jugador usa carta de Objetos ↓ InventarioFacade.obtener_objeto_aleatorio_y_guardar(calidad) ↓ ObjectPoolObjetos.obtener_objeto_aleatorio(calidad) ├→ Selecciona tipo aleatorio de la calidad └→ _obtener_desde_pool(tipo) ├→ Si pool tiene: pop() └→ Si no: FabricaObjetos.crear_objeto(tipo) ↓ Se guarda en inventario (máx 5)

Flujo 3: Usar Objeto

Jugador selecciona objeto del inventario ↓ InventarioFacade.usar_objeto(indice) ├→ Valida: no usado en turno actual └→ Valida: índice válido ↓ ObjetoBase.aplicar(jugador, enemigo, contexto) └→ Aplica efecto específico ↓ Devolución: ObjectPoolObjetos.devolver_objeto()

Flujo 4: Hacer Reroll

Jugador elige hacer reroll ↓ GestorMemento.guardar(jugador) → Captura estado actual ↓ Jugador.hacer_reroll() ├→ Valida: puede hacer reroll ├→ Incrementa contador └→ Genera nuevos dados (valor más alto) ↓ Penalización: pierde dados en próximo turno

Flujo 5: Transición de Turno

TurnoManager.pasar_turno() ↓ FASE 1 - InicioTurnoHandler ├→ jugador.iniciar_turno() ├→ Genera nuevos dados ├→ Aplica efectos DOT └→ Resetea contadores ↓ FASE 2 - AccionHandler ├→ Permite usar cartas ├→ Permite usar objeto (máx 1) └→ Permite reroll ↓ FASE 3 - FinTurnoHandler ├→ Finaliza efectos └→ Cambia al siguiente jugador
